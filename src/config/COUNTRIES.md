Country codes: public-domain IANA tzdata iso3166.tab (2025-07-01 dataset, ISO 3166-1 alpha-2).
EN/LV/RU display names: generated once with Node Intl.DisplayNames and sorted per locale.
The committed JSON prevents server/browser ICU differences from causing hydration mismatches.
Flags are Unicode regional-indicator pairs. Forms submit ISO codes; names and flags are presentation only.
